An editable project-card generator. Required fields are project name, GitHub repository, stars, screenshot and brief description. Users change block size, fonts, positions, spacing and themes and choose ready-made templates.
## Operating Context
Russian-language desktop editor with responsive access. No deployment target specified. No account or server required for local editing.
