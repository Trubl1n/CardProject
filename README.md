# Forma — редактор карточек проектов

React + TypeScript + Vite. Сборка статическая: сервер приложения и ключи для редактирования не нужны.

```sh
npm ci
npm run dev
npm run build
npm run preview
```

## Использование

Выберите шаблон, формат и тему. Нажмите на блок на холсте: справа появятся текст, шрифт, размер, начертание, выравнивание, координаты, габариты, внутренний отступ и скругление. Блоки перетаскиваются; нижний правый маркер меняет размер. Стрелки клавиатуры сдвигают выбранный блок. Вкладка «Слои» управляет видимостью.

Загрузите скриншот с устройства (до 6 МБ) или используйте встроенную демонстрацию. GitHub-импорт принимает `owner/repository` или HTTPS-ссылку и получает публичное имя, описание, репозиторий и звёзды. GitHub API требует сетевого доступа к api.github.com и может ограничивать частоту запросов. При ошибке поля доступны для ручного ввода. Приложение не запрашивает токены.

Изменения сохраняются в localStorage текущего браузера. Это не облачная синхронизация: очистка данных браузера удалит карточки. PNG экспортируется шириной 1080 px, высота зависит от формата. Направляющие и выделение в экспорт не попадают.

Демонстрационные данные и изображение интерфейса иллюстративные. Анализ исходных правил: docs/reference-analysis.md.

## Проверка

`npm run build` проверяет TypeScript и собирает production-версию. Браузерная проверка при реализации охватила редактирование, темы, сохранение, дублирование, шаблоны, PNG 1080 × 1350 и отсутствие горизонтального переполнения на 390 px.
